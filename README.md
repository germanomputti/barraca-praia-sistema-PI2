ProjetoBarracaPraia_Final

Como rodar (local)
Requisitos: Node.js >=16

1. Instale dependências
   npm install

2. Inicie o servidor
   npm start

3. Acesse no navegador:
   - Cliente: http://localhost:3000/index.html
   - Produção: http://localhost:3000/producao.html
   - Análise: http://localhost:3000/analise.html

O banco SQLite (db.sqlite) será criado automaticamente.
A API Open-Meteo é usada para buscar dados de clima (Praia Grande lat=-24.00 lon=-46.41).
